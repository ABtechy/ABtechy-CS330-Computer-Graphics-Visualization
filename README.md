# ABtechy-CS330-Computer-Graphics-Visualization
How do I approach designing software?

When I design software, I like to start by figuring out the overall goal and then breaking it down into smaller pieces. For this project, I spent time thinking about what I wanted my scene to look like before I started building it. One of the biggest things I learned was how to take complex objects and create them using simple shapes and transformations. I built my scene one object at a time and made adjustments as I went. This approach helped me stay organized and made it easier to fix problems when they came up. I can see myself using the same process in future projects because it helps make larger tasks feel more manageable.

How do I approach developing programs?

I usually develop programs by working on small sections at a time and testing frequently. During this project, I added features gradually instead of trying to build everything at once. One strategy that really helped was isolating problems when something wasn't working. A good example was when a texture was causing my project to crash. Instead of changing a bunch of things at once, I tested each texture individually until I found the issue. Iteration was a big part of my development process because every milestone built on the previous one. As the course progressed, I became much more comfortable troubleshooting issues, modifying code, and making improvements based on what I saw during testing.

How can computer science help me reach my goals?

This course gave me experience with computational graphics, visualization, textures, lighting, transformations, and debugging. While I don't see myself specializing in graphics programming, I gained a lot of problem-solving skills that apply to software development in general. Learning how to break larger projects into smaller tasks, test often, and troubleshoot issues methodically will help me in future courses and projects. Professionally, these skills will be useful because software development is not just about writing code. It's also about understanding how systems work, finding solutions when things go wrong, and continuously improving your work. This project helped strengthen those skills while also giving me a better understanding of how graphical applications are created.
